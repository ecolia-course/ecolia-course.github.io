📲 Installer ECOLIA

Installe l'app sur ton téléphone pour y accéder hors ligne, comme une vraie application.

⬇️ Télécharger l'APK Android (Version Classique)

Version 1.0 — Signée, compatible Android 7+

📱 Installation sur iPhone / iPad

  1. Ouvre cette page dans Safari (pas Chrome)
  2. Appuie sur le bouton Partager ⬆️
  3. Fais défiler et choisis "Sur l'écran d'accueil"
  4. Appuie sur "Ajouter" en haut à droite
  5. L'app apparaît sur ton écran d'accueil ✅

Aucun compte Apple requis. Gratuit à vie.

Sur ordinateur, tu peux utiliser l'app directement dans ton navigateur. Sur mobile, ouvre cette page depuis ton téléphone pour l'installer.
